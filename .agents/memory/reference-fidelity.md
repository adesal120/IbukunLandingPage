---
name: Portfolio reference fidelity
description: How to apply supplied redesign references and preserve existing destinations.
---

Treat supplied portfolio HTML, screenshots, and PDFs as exact copy and layout references rather than loose inspiration. Keep complete descriptions, proof points, year labels, and section order.

**Why:** The user corrected a previous redesign that abbreviated selected-work copy and substituted “Selected” for award and press years.

**How to apply:** Compare each section with the latest supplied reference, preserving existing live destinations unless the new source explicitly replaces them. Do not infer publication years from whether a headline contains a year.
